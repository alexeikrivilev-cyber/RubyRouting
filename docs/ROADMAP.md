# Roadmap — dimensions toward 10/10

Program: **v0.4.4 / SPEC-021 — ACTIVE**.

There is no fixed feature sequence. The agent chooses the highest expected-value work after fresh audit. Current dimensions are:

1. **Semantic correctness** — no hard-gate, state, fallback, accounting or output-contract defect.
2. **Scoring quality** — stable, exact, explainable multi-objective decisions with explicit target provenance.
3. **Causal explainability** — distinguish hard exclusion, selection rationale, provider outcome and fallback.
4. **Feasibility/analytics** — explain target deviations and produce quantitative actionable recommendations.
5. **Configurability/extensibility** — typed provider/factor policy without hidden provider branches or second routers.
6. **Judge-visible evidence** — deterministic scenarios for every scored strategy/conflict/analytics row.
7. **Submission reliability** — preserve SPEC-020 explicit queue, validators, business calendar, manifest and exact artifacts.
8. **Skeptical closure** — blind audits and clean final rehearsal before completion.

Do not spend hackathon time on infrastructure that does not materially improve one of these dimensions.
